## ETAP 0 — mapa ścieżek zapisu `PlanItem` / `PlanItemPortion`

Skróty:

- WPS = `src/weekly-plans/weekly-plans.service.ts`;
- APS = `src/agent/proposals/agent-proposals.service.ts`;
- EXE = `src/agent/tools/agent-tool-executor.ts`;
- PLN = `src/agent/planner/agent-meal-planner.service.ts`.

Stan na HEAD bazy (`f316f90`). Model współbieżności:

- „zamek” = `lockWeekForWrite` jako pierwsza blokada transakcji (READ COMMITTED; `applyWeekPlan` i `clearWeekPlan`
  — SERIALIZABLE z ponowieniem);
- „propozycja” = `guard` z odciskiem tygodnia (`baselineHash` / `appliedHash`) pod zamkiem.
