// Kasuje wszystkich uzytkownikow i wszystkie gospodarstwa. Katalog przepisow
// PRZEZYWA: skrypt najpierw przenosi przepisy z `isCatalog = true` na konto
// bota importu i do gospodarstwa katalogu, dopiero potem kasuje reszte.
// Bez tego `Recipe.household`/`Recipe.author` (oba onDelete: Cascade)
// zabralyby katalog razem z kontami.
//
// 1. Raport, nic nie kasuje — ZAWSZE najpierw to:
railway run --service Backend pnpm accounts:reset
//
// 2. Wykonanie:
railway run --service Backend RESET_ACCOUNTS_WRITE=true pnpm accounts:reset
//
// 3. Natychmiastowe wylogowanie WSZYSTKICH telefonow.
//    Sam punkt 2 tego NIE robi: access token jest podpisany na 30 dni
//    (JWT_EXPIRES_IN) i pozostaje wazny mimo skasowanego konta. Podmiana
//    sekretu uniewaznia kazdy wydany token — iOS dostaje UNAUTHORIZED,
//    probuje refresh (ktorego juz nie ma) i schodzi na ekran logowania.
//    Nowa wartosc: min. 32 znaki, INNA niz REFRESH_TOKEN_PEPPER
//    (assert-env odmawia startu, gdy sa rowne).
railway variables --service Backend --set "JWT_SECRET=$(openssl rand -hex 32)"
//
// 4. Kontrola po wszystkim:
railway logs --service Backend -d -n 50
railway run --service Backend pnpm accounts:reset   // ma pokazac 1 uzytkownika i 1 gospodarstwo
